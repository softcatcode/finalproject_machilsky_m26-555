# ValutaTrade Hub

ValutaTrade Hub — консольное приложение для управления валютным портфелем. Оно позволяет регистрировать пользователей, вести балансы в разных валютах, покупать и продавать валюту, получать обменные курсы и просматривать локальный кэш курсов.

Проект реализован на Python с использованием `uv` для управления зависимостями. Бизнес-логика отделена от CLI, а получение и хранение курсов вынесено в Parser Service.

## Возможности

- Регистрация пользователей и проверка учётных данных.
- Создание начального портфеля с балансом 10 000 USD.
- Просмотр валютного портфеля и его оценочной стоимости.
- Покупка и продажа валюты с проверкой доступного баланса.
- Получение обменного курса между валютами.
- Обновление локального кэша курсов через API.
- Просмотр курсов из локального кэша без обращения к API.
- Проверка корректности сумм и обработка ошибок.
- Логирование операций и хранение данных в JSON-файлах.

## Установка

Требуется Python 3.13 или новее и установленный `uv`.

Клонируйте репозиторий или перейдите в каталог проекта:

```bash
cd finalproject_machilsky_m26-555
```

Установите зависимости и синхронизируйте окружение:

```bash
uv sync
```

Проверьте доступность CLI:

```bash
uv run wallet --help
```

## Запуск приложения

### Интерактивный режим

Запустите приложение:

```bash
uv run wallet
```

В интерактивном режиме вводите команды после приглашения `>`.

Для просмотра доступных команд введите:

```text
help
```

Для завершения работы введите:

```text
exit
```

Важно: авторизация хранится в памяти текущего процесса. Чтобы выполнить несколько операций с портфелем в рамках одной сессии, используйте интерактивный режим и сначала выполните `login`.

### Однокомандный режим

Команды также можно запускать отдельно через `uv run wallet`. Например, для регистрации:

```bash
uv run wallet register --username SoftCat --password 'ExamplePass123'
```

Для команд, требующих авторизации, используйте интерактивный режим: отдельный запуск CLI создаёт новую сессию.

Не используйте реальные пароли в примерах, публичных логах или демонстрационных материалах.

## Команды CLI

### 1. Регистрация

```bash
uv run wallet register --username SoftCat --password 'ExamplePass123'
```

При успешной регистрации создаётся пользователь с начальным балансом 10 000 USD.

Повторная регистрация существующего имени пользователя должна завершаться понятным сообщением об ошибке.

### 2. Авторизация

В интерактивном режиме:

```text
login --username SoftCat --password 'ExamplePass123'
```

После успешного входа приложение сохраняет пользователя в текущей сессии.

### 3. Просмотр портфеля

После авторизации:

```text
show-portfolio
```

Можно указать базовую валюту для оценки портфеля:

```text
show-portfolio --base USD
```

### 4. Покупка валюты

```text
buy --currency SOL --amount 0.5
```

Приложение проверяет сумму, доступный баланс и курс. При успешной покупке средства списываются с баланса в USD, а купленная валюта добавляется в портфель.

### 5. Продажа валюты

```text
sell --currency SOL --amount 0.2
```

Приложение проверяет количество доступной валюты и зачисляет выручку в USD.

### 6. Получение обменного курса

```text
get-rate --from BTC --to USD
```

Команда запрашивает курс указанной валютной пары через бизнес-логику приложения.

### 7. Обновление курсов

Обновление с CoinGecko:

```bash
uv run wallet update-rates
```

Выбор источника CoinGecko явно:

```bash
uv run wallet update-rates --source coingecko
```

Выбор ExchangeRate-API:

```bash
uv run wallet update-rates --source exchangerate
```

Доступные источники: `coingecko` и `exchangerate`. Если источник не указан, используется `coingecko`.

### 8. Просмотр локальных курсов

Показать доступные курсы:

```bash
uv run wallet show-rates
```

Показать курс конкретной валюты относительно USD:

```bash
uv run wallet show-rates --currency EUR --base USD
```

Показать несколько криптовалют с наибольшим курсом относительно USD:

```bash
uv run wallet show-rates --top 3 --base USD
```

Эта команда читает локальный кэш и не требует запроса к API.

## Parser Service и настройка API

Parser Service получает данные из внешних источников, преобразует их в единый формат и сохраняет в локальное хранилище.

Для ExchangeRate-API может потребоваться API-ключ. Создайте файл `.env` в корне проекта:

```dotenv
EXCHANGERATE_API_KEY=your_api_key_here
```

Замените `your_api_key_here` действительным ключом. Не добавляйте `.env` в Git и не публикуйте ключ.

Настройки Parser Service включают:

- список поддерживаемых фиатных валют и криптовалют;
- соответствие кодов криптовалют идентификаторам CoinGecko;
- базовую фиатную валюту USD;
- пути к файлам курсов и истории;
- тайм-аут HTTP-запросов.

CoinGecko и ExchangeRate-API могут предоставлять разные наборы данных и иметь разные ограничения доступа. Для успешного обновления требуется доступ к соответствующему API.

## Локальное хранение данных и кэширование

По умолчанию используются следующие файлы:

| Файл | Назначение |
|---|---|
| `data/users.json` | Данные зарегистрированных пользователей |
| `data/portfolios.json` | Состояние валютных портфелей |
| `data/rates.json` | Текущий кэш обменных курсов |
| `data/exchange_rates.json` | История обменных курсов |
| `logs/` | Файлы логов приложения |

Настройки приложения в `pyproject.toml` включают:

- базовую валюту — USD;
- каталог данных — `data`;
- каталог логов — `logs`;
- TTL курсов — 300 секунд.

TTL (Time To Live) — период актуальности кэшированных данных. После истечения этого периода курсы считаются устаревшими согласно правилам бизнес-логики приложения. Команда `update-rates` позволяет обновить локальный кэш.

Формат и доступность данных зависят от успешного ответа выбранного источника.

Запустить автоматические тесты:

```bash
uv run pytest -q
```

Проверить код с помощью Ruff:

```bash
uv run ruff check .
```

Автоматические тесты охватывают основные сценарии регистрации, авторизации, проверки ошибок и операций с валютным портфелем.

При разработке рекомендуется запускать обе команды после изменений.

## Обработка ошибок

Приложение проверяет корректность входных данных и обрабатывает распространённые ошибки:

- неверное имя пользователя или пароль;
- повторная регистрация;
- недостаток средств для покупки;
- попытка продать больше валюты, чем доступно;
- нулевая, отрицательная или некорректная сумма;
- отсутствие курса для выбранной валютной пары;
- ошибки обращения к внешнему API;
- ошибки чтения и записи локальных данных.

Для ожидаемых ошибок CLI выводит понятные сообщения пользователю.

## Логирование

Конфигурация логирования находится в `valutatrade_hub/logging_config.py`. В проекте также предусмотрен декоратор `@log_action` для журналирования операций.

Логи помогают анализировать выполнение операций и диагностировать ошибки. Перед публикацией проекта убедитесь, что в логах нет паролей, API-ключей и других конфиденциальных данных.

## Демонстрационный сценарий

Для демонстрации основных возможностей:

1. Запустите `uv run wallet`.
2. Зарегистрируйте нового пользователя командой `register`.
3. Войдите через `login`.
4. Просмотрите портфель через `show-portfolio`.
5. Купите валюту через `buy`.
6. Продайте часть валюты через `sell`.
7. Получите курс через `get-rate`.
8. Обновите курсы командой `update-rates`.
9. Просмотрите локальный кэш через `show-rates`.
10. Продемонстрируйте обработку ошибок: неверный пароль, повторную регистрацию, недостаточный баланс, продажу сверх доступного количества и нулевую сумму.

Для повторяемой демонстрации используйте отдельного тестового пользователя и не включайте реальные учётные данные в запись экрана.

## Безопасность

- Не храните API-ключи и пароли в исходном коде.
- Не публикуйте `.env` и пользовательские данные.
- Не включайте виртуальное окружение `.venv`, кэши Python и личные логи в сдаваемый архив.
- Используйте тестовые учётные данные при демонстрации.
